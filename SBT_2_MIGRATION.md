# sbt 2.0 Migration Plan

This document tracks the migration of redis4cats from sbt 1.x to sbt 2.0.

## Background

sbt 2.0 (currently at RC9, Feb 2025) introduces several breaking changes:

- **Build definitions use Scala 3** instead of Scala 2.12
- **Requires JDK 17+** to run the metabuild
- **Bare settings apply to all subprojects**, reducing the need for `ThisBuild` scoping
- **`test` changed to incremental test**
- Apache Ivy is being phased out in favor of Coursier-based resolution

## Completed: Preparation Changes

These changes are forward-compatible with sbt 1.x and prepare the codebase for sbt 2.0.

### 8. Optional: Simplify `ThisBuild` usage

In sbt 2.0, bare settings in `build.sbt` apply to all subprojects by default. The `ThisBuild /` prefix is still supported but no longer necessary for most settings. Consider removing it from:

- [ ] `ThisBuild / scalaVersion`
- [ ] `ThisBuild / crossScalaVersions`
- [ ] `ThisBuild / evictionErrorLevel`
- [ ] `ThisBuild / mimaBaseVersion`
- [ ] `ThisBuild / organization`
- [ ] `ThisBuild / homepage`
- [ ] `ThisBuild / licenses`
- [ ] `ThisBuild / developers`
